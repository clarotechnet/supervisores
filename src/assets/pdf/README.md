# Fontes incorporadas no PDF

Noto Sans Regular e Bold, sem modificações, usadas somente ao gerar o PDF no navegador.
Licença SIL Open Font License 1.1, preservada em `OFL.txt`.

Origem: https://github.com/notofonts/noto-fonts/tree/ffebf8c1ee449e544955a7e813c54f9b73848eac/hinted/ttf/NotoSans

As fontes são servidas pelo próprio aplicativo, sem enviar os dados da escala a serviços externos.
O logo é desenhado com a mesma geometria vetorial de `public/technet-logo.svg`.
